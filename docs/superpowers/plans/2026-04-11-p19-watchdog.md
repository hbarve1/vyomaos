# P19 Watchdog — Silent-App Detection + Restart with Backoff

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supervisor kills and restarts any app that produces no stdout for longer than its declared `watchdog_secs` timeout, with exponential backoff between restarts.

**Architecture:** Three additions to `supervisor/src/main.rs`: (1) `watchdog_secs: u32` optional field in `Capabilities`; (2) per-app `last_output: Arc<Mutex<Instant>>` timestamp updated by the existing reader thread; (3) a new global watchdog thread that ticks every second and kills apps that have been silent too long. Backoff is tracked in a per-app `watchdog_backoff: u64` field (seconds until next allowed restart). No changes to any app or kernel.

**Tech Stack:** Rust, x86_64-unknown-linux-musl (supervisor). Build via Docker.

## Task 1: Unit tests for watchdog backoff calculation

**Files:**
- Create: `supervisor/tests/watchdog_test.rs`

- [ ] **Step 1: Create test file**

Create `supervisor/tests/watchdog_test.rs`:

```rust
/// Compute the next backoff after `restarts` watchdog-triggered restarts.
/// Doubles each time, capped at 300 seconds.
fn next_backoff(watchdog_secs: u32, restarts: u32) -> u64 {
    let base = watchdog_secs as u64;
    let factor = 1u64 << restarts.min(8); // 2^restarts, max 256
    (base * factor).min(300)
}

#[test]
fn first_restart_equals_watchdog_secs() {
    assert_eq!(next_backoff(5, 0), 5);
}

#[test]
fn second_restart_doubles() {
    assert_eq!(next_backoff(5, 1), 10);
    assert_eq!(next_backoff(5, 2), 20);
    assert_eq!(next_backoff(5, 3), 40);
}

#[test]
fn caps_at_300() {
    assert_eq!(next_backoff(5, 7),  5 * 128); // 640 → capped at 300
    assert_eq!(next_backoff(5, 7),  300);
    assert_eq!(next_backoff(5, 20), 300);
}

#[test]
fn watchdog_disabled_at_zero() {
    // watchdog_secs=0 means disabled; backoff is meaningless but shouldn't panic
    assert_eq!(next_backoff(0, 0), 0);
    assert_eq!(next_backoff(0, 5), 0);
}
```

```rust
    let base = watchdog_secs as u64;
    let factor = 1u64 << restarts.min(8);
    (base * factor).min(300)

```

- [ ] **Step 2: Spawn the watchdog thread after all apps are started**

After the loop that spawns all apps, add:

```rust
// ── P19: watchdog thread ───────────────────────────────────────────────────────
{
    let registry = Arc::clone(&app_registry); // Arc<Mutex<HashMap<String, AppEntry>>>
    thread::spawn(move || {
        loop {
            thread::sleep(Duration::from_secs(1));
            let mut reg = registry.lock().unwrap();
            for (name, entry) in reg.iter_mut() {
                let wsecs = entry.manifest.capabilities.watchdog_secs;
                if wsecs == 0 { continue; }

                // Check backoff
                let backoff = *entry.watchdog_backoff.lock().unwrap();
                if backoff > 0 {
                    *entry.watchdog_backoff.lock().unwrap() -= 1;
                    continue;
                }

                // Check silence
                let elapsed = entry.last_output.lock().unwrap().elapsed();
                if elapsed.as_secs() >= wsecs as u64 {
                    if let Some(child) = entry.child.as_mut() {
                        eprintln!("[watchdog] {name}: silent for {}s — killing", elapsed.as_secs());
                        let _ = child.kill();
                    }
                    // Set backoff for next restart
                    let restarts = entry.restarts;
                    *entry.watchdog_backoff.lock().unwrap() =
                        watchdog_next_backoff(wsecs, restarts);
                    // Reset timer so we don't immediately re-trigger
                    *entry.last_output.lock().unwrap() = std::time::Instant::now();
                }
            }
        }
    });
}
```

Note: `entry.child`, `entry.restarts`, `entry.manifest` — adjust field names to match the actual `AppEntry` struct fields found in Task 3 Step 1.
