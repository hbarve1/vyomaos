## Vision

VyomaOS Desktop is a capability-secure, WASM-first operating system with the full feature depth of macOS:
- Every app is a `wasm32-wasip2` binary; the kernel never executes app code
- A Rust PID-1 supervisor owns all policy: display, input, IPC, lifecycle, security
- Linux 5.10+ kernel handles hardware only; all OS personality lives in userspace Rust
- API surface exposed to apps: VYOMA_DRAW v3, VYOMA_INPUT, VYOMA_IPC, VYOMA_FS, VYOMA_NET, VYOMA_AUDIO, VYOMA_NOTIFY

## 1. Kernel & Process Model

**Status:** ✅ Debated & synthesized (2026-05-29)
**Debate:** [Architect: 924 lines] [Critic: 508 lines] [Final: 1334 lines]

### Key decisions
- **Embed Wasmtime as a library**, not as a `wasmtime run` subprocess per app. This is the prerequisite for distinguishing 12 distinct `CrashKind` variants (traps, mem limits, CPU limits, watchdog kill, host OOM, callback traps, etc.) versus today's single "non-zero exit" signal.
- **Sharded `AppTable`** (16 `RwLock` shards + `DashMap` name index) replaces the global `Mutex<HashMap>` registry. Eliminates the ~15-app perf wall; combined with `AppState` hot/cold split and `arc_swap::ArcSwap<Surface>`, compositor reads are lock-free.
- **WIT-typed `vyoma:lifecycle/callbacks`** interface (`on-timer`, `on-net-complete`, `on-suspend`, `on-resume`, `on-terminate`, `on-restart`, `on-focus-changed`, `on-ipc`) becomes the authoritative event-delivery mechanism. Stdin-line protocol is downgraded to a legacy fallback for printf-only demo apps. This is the only honest way to express background execution under WASI P2.
- **Wasmtime epoch interruption** (~1-3% overhead) replaces fuel-based CPU budgeting (20-40% overhead). Combined with `ResourceLimiter` trait for memory and table growth, this provides hard CPU and memory caps with negligible cost.
- **`BootPhase` enum + `BootBarrier`** with documented lock-order discipline (BootBarrier → InstallRegistry → AppTable shards → AppState.cold → AppState.hot → IPC inbox → CompositorState → Surface) eliminates the three boot races (display-before-init, inbox-before-reader, focus-lottery) and prevents ABBA deadlocks.
- **`AppIdentity` + `InstanceId` split** (stable bundle ID install-time vs `NonZeroU32` runtime instance) supports macOS-style multi-instance apps. IPC addressing grammar: `@<bundle>:`, `@<bundle>#<iid>:`, `@@focused:`, `@supervisor:`.
- **Five-actor decomposition** (LifecycleActor, IpcRouter, Compositor, InputDispatcher, WatchdogActor), all communicating via `crossbeam::channel::bounded` with explicit per-class overflow policies (drop-oldest / coalesce / NACK / fail-with-error).
- **State restoration via `StateBlob`** returned from `on-suspend`, persisted to `/data/state/<bundle>.bin`, delivered to `on-resume` on next launch. Suspended apps fully release linear memory (store dropped) — not parked in RAM.

### Critical v1 requirements
- App bundle ID + reverse-DNS naming (`AppIdentity`)
- Multi-instance launch (`InstanceId` + `AppTable`)
- LaunchServices / URL handler registration (`/data/registry/handlers.toml`)
- XPC-equivalent typed RPC (WIT callbacks + typed `IpcEnvelope`)
- Keychain / secrets (supervisor-owned encrypted KV; referenced, implementation in subsystem #20)
- Notifications (toast generalization; subsystem #17)
- State restoration after kill (`on-suspend` / `on-resume`)
- Crash reports persisted to `/data/crashes/<ts>-<bundle>-<iid>.toml`
- Sandboxing entitlements (existing capability model + signing)
- Code signing (ed25519, trust roots in `/etc/vyoma/trust/`)
- Quarantine / first-launch dialog (signature verification gate)
- Per-app process priority (`focus_priority` + epoch-tick weighting)
- Activity Monitor data (extended mgmt protocol)
- Typed pasteboard + drag-and-drop (subsystem #14)
- Global shortcuts (input dispatcher prefix-chord matching)
- Background tasks (`BackgroundTask` + WIT callbacks)

### Deferred to v2
- Login sessions / multi-user
- App Nap / energy management
- App Groups (shared containers)
- File coordination (NSFileCoordinator)
- Spotlight / metadata indexing
- Print system (CUPS-equivalent)
- Accessibility / AX API (REQ for compliance but XL effort)
- Per-app firewall
- Time Machine snapshot integration
- Per-app input methods
- Universal Links
- Document-based app model
- Push notifications (APNs)
- App extensions / share sheet

### Explicitly NEVER
- Mach ports (replaced by capability handles)
- Dynamic library loading / `dlopen` (WASM cannot)
- AppleEvents / AppleScript (replaced by typed IPC)
