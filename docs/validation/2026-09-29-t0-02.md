## Failures preserved

The Python outcomes reproduce the previous [T0-01 baseline](2026-09-29-t0-01.md): mismatched assertion/QMP APIs, unit-test deletion of the live VM's shared log, and a black central-window region. The default clock guest's previously observed unsupported-thread/restart defect is still open. Passing smoke/screenshot scripts do not prove healthy guest operation.

The first clean image attempt exposed a missing trust store in the minimal Ubuntu base. The fix bootstraps CA certificates from a checksum-pinned Ubuntu package before HTTPS apt access. TLS verification and apt archive signatures remain enabled; historical snapshot metadata expiry alone is disabled. No fallback to floating package sources was used.

Task boundaries: platform/config propagation and stale kernel handling remain T0-03; the terminal image allowlist is T0-04; test API/isolation/readiness repairs remain T0-05/T0-06. This change does not claim bit-for-bit reproducible images, updated release security qualification, installed-disk acceptance, or a completed terminal desktop.
