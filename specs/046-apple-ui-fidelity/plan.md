# Implementation Plan: Apple-Platform UI Fidelity

**Branch**: `046-apple-ui-fidelity` | **Date**: 2026-05-26 | **Spec**: [spec.md](spec.md)

---

## Summary

Upgrade VyomaOS from an 8×16 bitmap-font, flat-color rendering pipeline to a composited, typographically rich UI matching the Apple platform design language. Six independent user-story streams: (1) scalable font rendering via `fontdue`, (2) PNG image/icon support via `lodepng`, (3) alpha compositing and drop shadows, (4) window chrome polish with rounded corners and animations, (5) system UI components (menus, context menus, notifications), (6) display-profile-aware form-factor adaptation (macOS / iOS / watchOS / tvOS / visionOS).

---

## Technical Context

| Item | Value |
|------|-------|
| Language | Rust stable — supervisor: `x86_64-unknown-linux-musl`; apps: `wasm32-wasip2` |
| Font rasterizer | `fontdue` v0.7 — pure Rust, no libc, coverage-bitmap API |
| PNG decoder | `lodepng` — pure Rust, direct RGBA output, ~0.7 MB binary delta |
| Alpha blending | Porter-Duff "over" operator, premultiplied alpha, in `supervisor/src/display/compositor.rs` |
| Drop shadow | Separable box blur (2 passes, radius 4) on offset window mask |
| Fonts shipped | Inter Regular+Bold (~377 KB OFL), IBM Plex Mono Regular+Bold (~265 KB OFL) |
| Testing | `cargo test` + unit tests per rendering subsystem |
| Target platform | Linux framebuffer `/dev/fb0` or virtio-gpu DRM |
| Performance goal | Animations ≥ 30fps, ≤ 300ms; boot time ≤ 5s preserved |
| Binary size budget | Supervisor ≤ 2.5 MB after fontdue + lodepng (up from ~700 KB — justified) |

| VI. Observability First | ✅ | Font load, image decode, animation start/end emit structured log lines |

  ```rust
          let key = (ch, (pt * 10.0) as u32, bold, mono);

                            advance_x: m.advance_width, bearing_y: m.bounds.ymin as i32 }
          })
      }
  }
  ```

  ```rust
      for dy in 0..dst_h {
          for dx in 0..dst_w {

              let sy = dy * img.height / dst_h;
              let i  = (sy * img.width + sx) as usize * 4;

      }
  ```

  ```rust
      assert!(r > 80 && r < 180); // partial red
  }
  ```

- [ ] Implement `blend_over(src: u32, dst: u32) -> u32` using Porter-Duff formula:
  ```rust
  pub fn blend_over(src: u32, dst: u32) -> u32 {
      let (sr, sg, sb, sa) = unpack(src);
      let (dr, dg, db, da) = unpack(dst);
      let sa32 = sa as u32;
      let da32 = da as u32;
      let a_out = sa32 + da32 * (255 - sa32) / 255;
      if a_out == 0 { return 0; }
      let b = |sc: u32, dc: u32| -> u8 {
          ((sc * sa32 + dc * da32 * (255 - sa32) / 255) / a_out) as u8
      };
      pack(b(sr as u32, dr as u32), b(sg as u32, dg as u32),
           b(sb as u32, db as u32), a_out as u8)
  }
  ```

- [ ] Replace framebuffer pixel-write path with `blend_over` call
